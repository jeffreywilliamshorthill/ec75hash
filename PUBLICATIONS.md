## Reading the evidence

Read the status notes, null results, precision distinctions and correction records in each repository. A preprint, an exploratory tool, a fitted lens and an archived dataset have different scopes. For current citation, use the exact archived version relevant to the measurement; concept DOIs identify the version family.
